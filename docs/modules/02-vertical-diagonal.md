# Módulo 2 — Vertical ↔ diagonal

## Objetivo

Mudar entre um plano vertical e um diagonal sem carregar automaticamente o mesmo padrão de aceleração para a nova trajetória.

## Ideia central

Roll define o plano; pitch executa a curva nesse plano. Quando o roll muda, a participação da gravidade também muda. Portanto, toda mudança de plano exige uma recalibração curta:

> novo plano → nova orientação → nova tendência → novo comando

## Quatro transições

1. Vertical para diagonal esquerda.
2. Vertical para diagonal direita.
3. Diagonal esquerda para vertical.
4. Diagonal direita para vertical.

## Exercício solo

Comece uma subida vertical. Próximo ao topo, faça um roll curto para escolher a saída diagonal. Pare o roll e continue o pitch. Mantenha o novo plano por meia volta antes de repetir.

Depois faça o inverso: entre numa diagonal ascendente e converta a trajetória em vertical.

## Gerenciamento de velocidade

- Não espere cair abaixo de 300 para corrigir uma subida forte.
- Ao transformar vertical em diagonal descendente, retire potência antes que a gravidade produza overspeed.
- Após o roll, faça uma checagem rápida de tendência; não pressione comandos por memória.

## Com parceiro

O parceiro anuncia `esquerda`, `direita` ou `vertical` antes do topo. Você executa a saída anunciada. Depois, ele deixa de anunciar e apenas demonstra o lado para você acompanhar.

## Erros comuns

- Fazer o roll e permanecer reto.
- Continuar afterburner depois de entrar em descida.
- Roll excessivo transformar a saída diagonal no sentido oposto.
- Corrigir velocidade e roll simultaneamente com comandos longos.

## Critério para avançar

- Executar as quatro transições para ambos os lados.
- Terminar cada mudança entre 300–320.
- Entrar no novo pitch imediatamente.
- Reconhecer verbalmente a nova orientação.
